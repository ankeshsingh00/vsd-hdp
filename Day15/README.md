# Day 15 - RISC-V Physical Design

## Theory

### What is RISC-V?
Open source ISA
Free to use!

### Why RISC-V?
- No licensing fee
- Open standard
- Used in industry
- Growing ecosystem

### RISC-V Instructions
- R type: Register operations
- I type: Immediate operations
- S type: Store operations
- B type: Branch operations
- U type: Upper immediate
- J type: Jump operations

### Physical Design Challenges
- Complex design
- Many flip flops
- Timing critical paths
- Large chip area

## Config Parameters
- Clock Period = 20ns (50MHz)
- Core Utilization = 35%
- Target Density = 0.35
